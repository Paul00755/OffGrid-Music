# Implementation Plan: Fix APK Installation Stopping Midway

## Problem Analysis
When the user downloads the APK generated by GitHub Actions, the Android PackageInstaller starts installing and terminates midway with no error, failing both on updates and fresh installs.

### Root Causes Identified & Resolved
1. **Keystore Inconsistency across Builds**:
   - In `.github/workflows/build-apk.yml`, the workflow generated a brand-new random debug keystore using `keytool -genkey` on every runner invocation because `debug.keystore` is ignored by `.gitignore`.
   - Android PackageInstaller verifies the signing certificate against the previously installed app. When they do not match, the installation terminates midway without error (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`).
   - The repository already contains `debug.keystore.base64` with the authoritative, persistent signing key.
   - **Resolution**: Updated `.github/workflows/build-apk.yml` to decode `debug.keystore.base64` into `debug.keystore` on every build. All future builds will have identical, consistent signing certificates.

2. **KSP CI Daemon Error**:
   - In the GitHub Actions screenshot, KSP crashed with:
     `Cannot invoke "ksp.com.intellij.openapi.application.Application.getService(java.lang.Class)" because the return value of "ksp.com.intellij.openapi.application.ApplicationManager.getApplication()" is null`
   - Running with `-Dkotlin.compiler.execution.strategy=daemon` on GitHub Actions caused KSP daemon metaspace and classloader desynchronization, producing incomplete APK packages.
   - **Resolution**: Configured Gradle to run with `--no-daemon -Dorg.gradle.jvmargs="-Xmx3072m -XX:MaxMetaspaceSize=768m"` on CI.

3. **Target SDK & Version Code**:
   - `versionCode` was at `1`, preventing PackageInstaller on many devices from properly upgrading.
   - `targetSdk = 36` (Android 16 Developer Preview) triggered sideloading verification blocks on devices running Android 14/13/12.
   - **Resolution**: Set `targetSdk = 35` (Android 15 stable) and bumped `versionCode = 2` (`versionName = "1.0.1"`).

## Important Next Steps for the User
1. Push your changes to GitHub (`git push`).
2. **Uninstall the old app from your phone once** (because the previous APK installed on your phone was signed with the temporary random key generated by the old GitHub Action run).
3. Download and install the new APK from GitHub Releases / Actions.
4. **All future updates** will install seamlessly as normal in-place updates without uninstalling!
